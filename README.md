##################################################################### Exercício Programa POO : Jogo RPG Textual #####################################################################

## DESCRIÇÃO : Programa em Java baseado na Programação Orientada a Objetos e na arquitetura MVC (Model-View-Controller) que executa um jogo RPG interativo baseado em texto.


## PRÉ-REQUISITOS:
		- Java JDK;


## FUNCIONALIDADES :
		- Criação de personagem customizado;
		- Sistema de combate;
		- Sistema de magias;
		- Tutorial de comandos;
		- Exploração do mapa com diferentes salas;
		- Interação com NPCs;
		- História com diferentes rumos;
		- Coleta e gerenciamento de itens em inventário;
		- Persistência de dados;


## USO :
	Para executar o jogo é necessário possuir o Java JDK instalado em seu computador. Em seguida, compile e execute o programa pela Main.
	
	Com o jogo em execução, você pode usar os seguintes comandos após a criação do seu personagem:
	
	[1] VER : Exibe uma descrição da sala atual em que você estiver e as direções que pode seguir.
	[2] FALAR : Te permite falar com um NPC na mesma sala que você.
	[3] ATACAR : Permite atacar um alvo.
	[4] INVENTARIO :  Permite atacar um alvo.
	[5] USAR : Mostra os itens e armas que você possui para usar.
	[6] EQUIPAR :  Permite trocar ou equipar uma arma.
	[7] MAGIAS : Exibe as magias que você pode usar.
	[8] TERMINAR : Salva e fecha o jogo a qualquer momento.
	
	C, B, D, E : Movimentam o jogador pelo mapa.
